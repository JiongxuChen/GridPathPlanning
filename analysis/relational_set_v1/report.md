## 输入通道诊断与边界

在**已打开的第二批面板**上事后保持文本、权重、候选不变，
只将数值偏移集合置空。[逐例通道消融](../../results/relational_set_multiseed_v1/channel_ablation.json)
中三个 seed 的受控碰撞联合都从 20/20 降至 4/20，
自然碰撞都从 21/21 降至 4/21。候选与文本 token 长度、
权重身份均核对一致，说明已训练模型**实际依赖**新增数值通道。
不过置空是分布外干预：seed 42、44 还把全部有效路径误判为
无效，不能将跌幅直接解读为“数值通道的纯因果增益”。

这些结果支持继续研究可学习集合表示，却尚不替换已封存的
“九格 V + 0.7 门控”：只有三 seed、两批针对性 6×6 布局，
没有在同一预定总体 ID/OOD 面板上和几何路线正面对照，
也未覆盖长路径及 8×8／10×10。原始偏移本身允许出现
`(0,0)`，即拟到达格恰为障碍；模型可学习此关系，但这不是
“不含几何信息”的输入。后续应预冻结总体评价，并检查
边界、长路径和障碍密度分布，而不是在这两批满分面板调参。
